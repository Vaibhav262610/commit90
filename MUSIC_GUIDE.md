# Music Player Guide

## How to Add Gym Bangers to Project 90

The music player in Project 90 supports **in-app playback** for direct audio files and external links for streaming services.

---

## In-App Music Player

### Supported Formats
The built-in player supports direct audio file URLs:
- `.mp3`
- `.wav`
- `.ogg`
- `.m4a`

### How It Works
1. Go to **Music** tab
2. Click **Add** button
3. Enter track name (e.g., "Eye of the Tiger")
4. Paste a **direct link** to an audio file
5. Click **Add Track**
6. Click the ▶️ play button to play it in-app

### Now Playing Controls
- ⏯️ Play/Pause
- ⏮️ Previous track
- ⏭️ Next track
- 🔊 Volume control

## Where to Find Free Workout Music

### 1. Free Music Archive
- **Website**: https://freemusicarchive.org
- Find royalty-free music
- Right-click → Copy link address to get direct MP3 URLs

### 2. YouTube Audio Library
- **Website**: https://youtube.com/audiolibrary
- Download MP3 files
- Host them on your own server or cloud storage
- Use the direct URL in Project 90

### 3. Incompetech
- **Website**: https://incompetech.com/music
- Free music by Kevin MacLeod
- Download MP3s and host them yourself

### 4. SoundCloud
- Some artists allow free downloads
- Look for "Free Download" tracks
- Get direct audio file URLs

### 5. Your Own Files
If you have MP3 files on your computer:
1. Upload them to a cloud service (Google Drive, Dropbox, OneDrive)
2. Get a **direct download link** (not a preview link)
3. Add it to Project 90

**Google Drive Example:**
- Upload MP3 → Share → Copy link
- Change `https://drive.google.com/file/d/FILE_ID/view`
- To `https://drive.google.com/uc?export=download&id=FILE_ID`

## Streaming Service Links

### Spotify
Spotify links open in a new tab (requires Spotify app or web player)
- Copy playlist URL from Spotify
- Add it in the **Spotify Connect** section

### YouTube
YouTube links open in a new tab
- Copy video or playlist URL
- Add as a music link
- Click to open in YouTube

### SoundCloud
SoundCloud links open in a new tab
- Copy track or playlist URL
- Add as a music link

## Tips

### For Best Experience
- Use 128-320 kbps MP3 files for good quality
- Keep file sizes reasonable (3-5 MB per song)
- Host files on reliable cloud storage

### Organizing Your Music
- Create separate playlists for different workout types
- Name tracks clearly (e.g., "Chest Day - Track 1")
- Use the volume control to set comfortable levels

### Legal Note
- Only add music you have the right to use
- Use royalty-free music or your own purchased tracks
- Respect copyright laws

## Troubleshooting

### "Error playing audio file"
- Make sure the URL is a **direct link** to an audio file
- Check that the file format is supported (.mp3, .wav, .ogg, .m4a)
- Ensure the URL is publicly accessible (not behind login)

### Music won't play
- Verify your internet connection
- Check browser console for CORS errors
- Try a different audio file URL

### External links not working
- Make sure you're clicking the ▶️ button
- Check that your browser allows pop-ups
- Verify the URL is correct
